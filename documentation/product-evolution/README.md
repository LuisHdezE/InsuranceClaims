# Product Evolution

This folder contains **post-MVP planning guidance** for the Insurance Claims Legacy Modernization case study.

These documents do **not** retroactively change the accepted MVP requirements, approvals or Blueprint lifecycle state. They are inputs for future governed scope decisions.

## Documents

- [`INSURANCE_OPERATIONS_PLATFORM_EVOLUTION.md`](INSURANCE_OPERATIONS_PLATFORM_EVOLUTION.md) — product/architecture analysis and target platform direction derived from additional insurance-operations reference material.
- [`TARGET_CAPABILITY_BACKLOG.md`](TARGET_CAPABILITY_BACKLOG.md) — candidate P0/P1/P2/Deferred implementation backlog extracted from that analysis.

## Scope rule

A capability listed here becomes committed implementation scope only after explicit selection, requirements/domain/interface impact analysis and human approval.

The active near-term sequence begins with finishing the public Home visual alignment, then deepening Claims Operations before expanding into broader insurance-operations modules.
