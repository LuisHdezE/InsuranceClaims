# Claims Workspace / Kanban — Referencia visual aprobada R3

Estado: APROBADA
Fecha de aprobación: 2026-09-12
Capability: Claims Workspace
Decisión de alcance: CORE

## Objetivo funcional

Permitir al operador encontrar, filtrar, comprender el estado general y seleccionar el siniestro sobre el que necesita trabajar.

## Principios visuales aprobados

- Interfaz visible en español.
- UI atractiva, profesional y compacta.
- Aprovechamiento alto del viewport.
- Tipografía contenida, sin títulos sobredimensionados.
- Padding y márgenes moderados, sin espacio ornamental innecesario.
- Mantener vistas Kanban y Lista como dos representaciones de la misma capacidad.
- Tarjetas compactas, orientadas a descubrimiento y triage.
- No incluir edición profunda, timeline, evidencia ni tareas dentro de las tarjetas.
- No implementar drag & drop mientras el contrato funcional no lo soporte.
- No confundir ClaimStatus con Operational Pipeline.
- No inventar controles o capacidades no expuestas por la aplicación/API.
